《从 OpenFGA 到 Mini-OpenFGA：从零构建 Zanzibar 式授权引擎》大纲 ​

参照仓库：openfga/openfga @ 526995eb（v1.22.0）；DSL 解析器来自外部包 openfga/language/pkg/go v0.3.2 读者目标：读完后，能从零写出一个前后端都能运行的 ReBAC 授权引擎：DSL 建模 → 元组存储 → Check / ListObjects / ListUsers → HTTP API → Playground UI。 写作方式：每章先讲概念，再读 OpenFGA 源码（路径:行号），再在 mini-openfga 里实现，最后贴真实运行输出。 正确性验收：mini-openfga 直接跑原仓库 assets/tests/*.yaml 的矩阵测试（挑能支持的子集），通过率写进书里。

贯穿全书的项目：mini-openfga ​

版本能力章节
v0.1手写 DSL 词法/语法解析器、TypeSystem 与模型校验、Tuple、内存存储、递归 Check（direct / computed / TTU / union / intersection / but not）、CLIPart II（4–8 章、Lab 1）
v0.2并发 Check：短路 union/intersection、exclusion、userset group#member、通配符 user:*、环检测、深度/广度限制、上下文元组Part III（9–13 章、Lab 2）
v0.3条件（CEL）、Resolver 链（缓存 + 限流）、Expand、BatchCheckPart IV（14–17 章、Lab 3）
v0.4ListObjects（反向展开、流式）、ListUsersPart V（18–20 章、Lab 4）
v0.5SQLite 存储、Store / 模型版本（ULID）、Write 校验、Read / ReadChanges、Assertions、一致性与缓存失效、HTTP APIPart VI（21–24 章、Lab 5）
v0.6Vite + React Playground：模型编辑、元组表、查询面板、解析树可视化Part VII（25–26 章、Lab 6）
v1.0Weighted Graph 与策略选择（v2 check）、Thompson Sampling Planner、API 鉴权（预共享密钥）、指标/追踪、Docker 部署、跑原仓库矩阵测试Part VIII（27–31 章、Lab 7）

默认技术栈：Go 1.26 + net/http（不用 gRPC/protobuf）、modernc.org/sqlite（纯 Go）、google/cel-go（和原仓库一致）、Vite + React + TypeScript。
